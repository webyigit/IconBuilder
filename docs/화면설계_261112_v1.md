# 아이콘 빌더 화면 설계 (v1, 2026-11-12)

## 화면 목록
| ID | 화면(탭) | 주요 요소 | 관련 기능 |
|---|---|---|---|
| S1 | 만들기 | ① 샘플 입력(파일·URL) ② 분석 결과(색·스타일) ③ 키워드·설명 ④ 생성 버튼 ⑤ 후보 4개 ⑥ 옵션 조정 ⑦ 내보내기 | F01~F07, F10 |
| S2 | 보관함 | 저장 아이콘 그리드, 검색, 형식별 다운로드, 삭제 | F08 |
| S3 | 참고 사이트 | 사이트 목록 표(이름·주소·검색주소), 추가·수정·삭제, 기본값 복원 | F09 |
| S4 | 설정 | 저장 위치(브라우저/Supabase), Supabase 주소·공개키, 생성 엔진 선택 | F11, F12 |

## 흐름
```
[만들기] 샘플 올리기(파일 or URL)
   → 자동 분석(색·선/면·둥글기)
   → 키워드·설명 입력 → [생성]
   → 후보 4개 중 선택 → 옵션 조정(실시간 미리보기)
   → 형식·크기 선택 → [다운로드] / [보관함 저장]
   → [보관함]에서 다시 받기·삭제
[참고 사이트] 키워드로 각 사이트 검색(새 탭) ← 만들기 화면에서도 바로가기
```

## 레이아웃
- 데스크톱: 왼쪽 입력 패널(380px) + 오른쪽 결과 영역.
- 모바일(<820px): 위아래 1단.
- 상단 탭 4개, 키보드 Tab 이동, 포커스 표시.
