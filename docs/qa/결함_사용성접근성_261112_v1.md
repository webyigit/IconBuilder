# 아이콘 빌더 사용성·접근성·호환성 검증 리포트 (261112 v1)

- 대상: http://localhost:8765/ (소스 `app/`), 화면 S1 만들기, S2 보관함, S3 참고 사이트, S4 설정
- 기준: `docs/요구사항_261112_v1.md`, `docs/화면설계_261112_v1.md`, WCAG 2.1 AA, 사이트 UX 체크리스트(B·C·D·E·F)
- 기기: Chromium(Playwright) 데스크톱 1280×900, iPhone 13, Pixel 7, 360×740, iPad(gen 7) 세로·가로 / 라이트·다크 모드
- 도구: Playwright, axe-core 4.x(wcag2a·aa·21a·21aa·best-practice), 대비 직접 계산, 스크린샷 직접 확인(deviceScaleFactor 1)
- 페르소나: 아이콘 경험이 적은 기획자. 과업: 샘플 올리기 → 키워드 입력 → 생성 → PNG 다운로드 → 보관함 저장
- 점검일: 2026-11-12 / 코드 수정 없음(검증만)

## 요약
- **치명 0 · 중요 7 · 경미 13**, 체크리스트 통과율 약 62%(26항목 중 16 통과)
- 핵심 과업(샘플→생성→PNG→보관함)은 마우스·키보드 모두 **완료 가능**. 파일 형식·크기·URL 오류 문구는 쉽고 원인+해결책이 있음. 포커스 표시, 레이블, 탭 화살표 이동, 후보 radiogroup 화살표 이동은 잘 되어 있음.
- 가장 큰 문제
  1. 생성 전부터 "스타일 조정·내보내기" 영역이 보이고, 깨진 미리보기 이미지·검은 색상칸이 나오며, 이때 다운로드·저장을 누르면 개발자용 영어 오류(`Cannot read properties of undefined`)가 뜸(UX-01).
  2. 휴대폰(390·412·360px)에서 상단 탭이 1개만 보이고 보관함·참고 사이트·설정 탭이 숨겨짐(UX-02).
  3. 다운로드·저장·삭제 후 키보드 포커스가 페이지 맨 앞(body)으로 사라짐(A11Y-01).
  4. 다크 모드 대비 미달: 오류 토스트 2.32:1, 참고 사이트 표 링크 1.75:1(A11Y-02, A11Y-03). 입력란 테두리 대비 1.26:1(A11Y-04).
- 360px 폭 포함 모든 기기에서 **페이지 가로 스크롤 없음**(scrollWidth = innerWidth). 태블릿은 세로 1단·가로 2단 모두 정상.

### 확인 필요(결함 집계 제외)
- **한글 파일명 다운로드**: 테스트 환경(headless Chromium)에서 파일명이 `장바구니_256px.png`가 아니라 `download`(확장자 없음)로 받아짐. 앱과 무관한 순수 `a.download='한글_테스트.txt'`도 같은 결과라 환경 문제로 판단. 영문 이름(`my-icon_vector.svg`)은 정상. 실제 Chrome·Safari·삼성 인터넷에서 한글 파일명 확인 필요. 파일 내용은 PNG·JPG·GIF·SVG 모두 256×256 정상.
- Firefox·WebKit은 이 환경에 설치되어 있지 않아 Chromium 에뮬레이션으로만 확인함. 실제 Safari(iOS) 확인 필요.

## 잘한 점
- 오류·빈 상태 문구가 짧고 친절함("~해 주세요", 다음 행동 제시). CORS 실패를 일반인 말로 설명.
- 후보 선택이 radiogroup + 로빙 tabindex + 화살표로 구현돼 키보드 조작이 자연스러움.
- 건너뛰기 링크, `:focus-visible` 외곽선, 표 헤더 `scope`, fieldset/legend 등 기본 접근성 구조가 탄탄함.
- 360px까지 가로 스크롤 없음, 참고 사이트 표가 모바일에서 카드형으로 바뀜.
- 실시간 미리보기와 16·24·32·48px 크기 미리보기가 초보자에게 이해를 도움.

## 용어 각주
- WCAG AA: 웹 접근성 국제 기준의 중간 등급. 글자 대비 4.5:1(큰 글씨 3:1), 컨트롤 경계 3:1 등.
- aria-live: 화면 내용이 바뀌면 스크린리더가 읽어 주도록 하는 표시.
- 로빙 tabindex: 묶음 안에서 하나만 Tab으로 들어가고 나머지는 화살표로 이동하는 방식.
- 리플로(1.4.10): 좁은 화면(320~360px)에서 가로 스크롤 없이 내용이 다시 배치되는 것.
