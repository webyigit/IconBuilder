- 대상: `app/` 정적 웹앱 (http://localhost:8765/), 요구사항 `docs/요구사항_261112_v1.md`

- 범위: 샘플 업로드·URL, 분석, 키워드 매칭, 후보 선택, 스타일 조정, 내보내기, 보관함, 참고 사이트, 설정

- 결함 등급: **치명 0 · 중요 5 · 경미 9** (+ 확인 필요 1)
