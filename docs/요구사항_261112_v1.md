# 아이콘 빌더 요구사항 (v1, 2026-11-12)

## 1. 목적
샘플 아이콘(이미지 파일 또는 URL)과 키워드·설명을 입력하면, 샘플과 비슷한 스타일의 아이콘을 만들어 PNG·JPG·GIF·SVG로 내려받고 저장하는 웹앱. 외부에서 웹 주소로 접속.

## 2. 사용자
| 사용자 | 하는 일 |
|---|---|
| 디자이너·기획자(주 사용자) | 샘플 올리기, 키워드 입력, 생성, 다운로드 |
| 관리자 | 참고 사이트 목록 관리, 저장된 아이콘 정리 |

## 3. 기능 목록
| ID | 기능 | 우선순위 | MVP |
|---|---|---|---|
| F01 | 샘플 이미지 업로드(PNG·JPG·GIF·SVG·WEBP, 드래그앤드롭, 최대 5MB) | 필수 | O |
| F02 | 샘플 이미지 URL 입력(불러오기 실패 시 안내) | 필수 | O |
| F03 | 키워드(쉼표 구분)·설명 입력 | 필수 | O |
| F04 | 샘플 스타일 분석: 주요 색, 선/면 스타일, 모서리 둥글기 추정 | 필수 | O |
| F05 | 아이콘 생성(후보 4개) | 필수 | O(가상 생성기) |
| F06 | 스타일 옵션 조정(색, 선 굵기, 채움/선, 배경 모양) | 중요 | O |
| F07 | 내보내기 PNG·JPG·GIF·SVG, 크기 선택(32~1024px) | 필수 | O |
| F08 | 생성 아이콘 저장·갤러리(검색·삭제·재다운로드) | 필수 | O(브라우저 저장) |
| F09 | 참고 사이트 목록 추가·수정·삭제(기본: Iconfinder, Font Awesome, Flaticon) | 필수 | O |
| F10 | 참고 사이트에서 키워드로 바로 검색(새 탭) | 중요 | O |
| F11 | 클라우드 저장(Supabase Storage·DB) | 필수 | 코드 준비, 연동은 승인 후 |
| F12 | AI 생성(Claude API, 샘플 이미지 보고 SVG 생성) | 필수 | 함수 코드 준비, 키 등록 후 |
| F13 | 접속 보호(간단 접근 코드 또는 로그인) | 중요 | 2차 |

## 4. 비기능
- 외부 접속: GitHub Pages 주소로 공개. 키는 브라우저 코드에 넣지 않음(서버 함수 비밀값).
- 모바일 화면 대응, 키보드 조작, 대비(WCAG AA[^1]).
- 저작권: 참고 사이트 아이콘을 복제하지 않고 "스타일 참고"만. 사이트 이미지 자동 수집(스크래핑) 안 함.

## 5. 구성안
| 안 | 구성 | 장점 | 한계 |
|---|---|---|---|
| A. GitHub만 | Pages + 저장소에 커밋 | 무료·단순 | 외부 사용자 업로드 시 토큰 노출 위험, 동시 저장 충돌 → **비권장** |
| **B. GitHub Pages + Supabase (권장)** | 화면은 Pages, 이미지·아이콘은 Storage, 목록은 DB, 생성은 Edge Function[^2] | 무료 한도 내 운영, 키 보관 안전, MCP 연결됨 | 무료 플랜은 1주 미사용 시 일시정지 |
| C. Cloudflare Pages + R2 + Workers | 전부 Cloudflare | 빠름, 저장 비용 낮음 | 현재 연결 도구 없음, 계정 설정 필요 |

## 6. 생성 엔진
| 엔진 | 필요한 키 | 결과 | 비고 |
|---|---|---|---|
| 가상 생성기(내장) | 없음 | 키워드 기반 기본 도형 + 샘플 색·스타일 반영 | MVP·시연용 |
| **Claude API (권장)** | Anthropic API 키 | 샘플 이미지 분석 후 SVG 직접 생성 | SVG라 확대·색 변경 쉬움 |
| OpenAI 이미지 API | OpenAI 키 | PNG 생성 | SVG는 변환 필요, 품질 편차 |
